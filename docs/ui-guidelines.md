# phpbox Desktop · UI 开发规约（AI 必须遵守）

- **状态**：采纳草案 v1.0（含 5 处修订，**待用户确认**——见文末修订记录）
- **来源**：外部草案经仓内核验修订后采纳。核验基础 = 终定稿原型实测（11 视图巡检、交互链路）+ ADR-001 + 设计文档 v2.0。
- **地位**：前端 UI 的唯一权威约束文档；与 ADR-001 / 设计文档冲突时，技术栈条款以 ADR-001 为准（冲突点见 §一【修订·待拍板】），其余以本文为准。
- **质量基线**：以下条款中，§7.5（抽屉 42px 常驻）、§8.5（布局预设/滑块/浏览按钮）、§6.3（危险弹窗勾选+输入匹配结构）、§4.1（尺寸变量化）已经终定稿原型实测符合；§17 无障碍与 §8.2 折叠预览为原型待修项。

## 零、总原则

1. **状态优先于操作**：任何页面打开时，第一眼必须是"现在什么状态"，而不是一排按钮。
2. **命令透明化**：任何写操作都要在弹窗中展示等价 phpbox CLI 命令，且可复制。
3. **长任务不阻塞**：任何耗时操作走底部抽屉，切页不中断。
4. **危险操作两段式**：删除类操作必须二次确认，--purge 类操作需输入匹配文本。
5. **乐观 + 回滚**：按风险×频率区分操作语义（详见 §6）。
6. **空状态给方向**：不是空白，是"下一步做什么"。
7. **错误可自愈**：给出可复制的 CLI 兜底命令。
8. **离线显性化**：安装命中缓存即亮"零网络"徽章。
9. **平台现实**：不臆造浏览器无法实现的能力，降级方案必须显式。
10. **引擎零依赖**：前端只通过绑定层调用引擎，不 import 任何引擎实现。

## 二、架构约束

### 2.1 目录边界

- 引擎代码在 `internal/engine/`，禁止 import 任何 Wails 包
- 平台差异只在 `internal/platform/`
- 前端只允许 `src/api/` 触摸 wailsjs 生成绑定
- 服务线之间禁止互相 import；跨线联动通过 registry 注册回调

### 2.2 数据流

- 静态数据（版本/站点/.env）：视图加载 + 任务结束 + 窗口聚焦时刷新
- 动态数据（容器状态）：仅总览页 8s 轮询兜底；引擎 Go 化后改为事件推送
- 日志：事件流订阅
- 禁止全量轮询

### 2.3 任务并发

- 默认单任务队列：running 中发起新任务 → Toast 拒绝
- 设置中可开启"允许并发"（默认关闭）
- 任务崩溃恢复：启动时查询任务锁，发现中断 → 通知中心提供"半安装清理"

## 三、视觉系统

### 3.1 主题（6 套，必选其一）

| ID | 名称 | 用途 |
| --- | --- | --- |
| midnight | 午夜蓝 | 默认深色 |
| light | 晨光白 | 日间浅色 |
| oled | 极夜黑 | 纯黑 OLED 省电 |
| forest | 森林绿 | 自然深绿 |
| ocean | 深海蓝 | 冷色深海 |
| sakura | 樱花粉 | 柔和浅粉 |

约束：

- 主题通过 `[data-theme="xxx"]` 切换
- 所有颜色必须走 CSS 变量，禁止硬编码色值
- 主题切换必须持久化到 localStorage（key：`phpbox-theme`）
- 切换必须即时预览（弹窗内点击卡片立即生效）
- 【补充·原型已实现】每主题声明 `color-scheme: dark/light`，原生控件跟随主题

### 3.2 色彩语义

| 变量 | 语义 | 使用场景 |
| --- | --- | --- |
| --accent | 主操作 / 高亮 | 主按钮、链接、激活项 |
| --ok | 成功 / 运行中 | 健康徽章、成功日志 |
| --warn | 警告 / 降级 | 未保存提示、降级状态 |
| --danger | 危险 / 失败 | 删除按钮、失败日志 |
| --text / --text-dim / --text-mute | 三级文字 | 主文/次文/提示 |

禁止：

- 禁止使用纯红 #f00 / 纯绿 #0f0 等饱和度过高的色值
- 禁止在强调色上叠加另一强调色
- 禁止用颜色以外的唯一手段传达状态（必须配合文字或图标）

### 3.3 尺寸与间距

| 项 | 值 | 说明 |
| --- | --- | --- |
| --r | 12px | 卡片、弹窗 |
| --r-sm | 8px | 按钮、输入框 |
| --r-xs | 6px | 小徽章、图标按钮 |
| 卡片间距 | 14–16px | grid gap |
| 区块间距 | 20–26px | margin-bottom |
| 内边距 | 16–22px | card padding |

禁止：

- 禁止使用 4px 以下的圆角
- 禁止使用超过 16px 的圆角（除非头像/圆形元素）
- 禁止使用 `!important`

### 3.4 字体

- 无衬线：-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", ...
- 等宽：ui-monospace, "SF Mono", "JetBrains Mono", Menlo, Consolas
- 基础字号 14px，行高 1.55
- 大屏（≥1600px）字号 +0.5px，超大屏（≥2200px）+1px
- 数字/版本号/路径必须用 --mono 字体

## 四、布局系统

### 4.1 三段式结构

```text
[侧边栏] [主内容区]
         [任务抽屉]
```

- 侧边栏宽度：默认 200px，可拖拽 64–380px
- 任务抽屉高度：默认 160px，可拖拽 120–600px
- 主内容区最大宽度：默认 1200px，随屏幕断点放大

### 4.2 可拖拽元素

| 元素 | 拖拽位置 | 双击行为 |
| --- | --- | --- |
| 侧边栏 | 右边缘 6px 热区 | 重置为 200px |
| 任务抽屉 | 上边缘 6px 热区（仅展开时） | 重置为 160px |
| 弹窗 | 右下角 16×16 手柄 | 无 |

拖拽时禁止：

- 禁止使用 drag API（用 mousedown/touchstart 手动管理）
- 拖拽中必须加 .resizing 类禁用过渡动画
- 必须同时支持鼠标和触摸

### 4.3 持久化

- 所有尺寸（侧边栏宽度、抽屉高度、主题）必须存入 localStorage
- key 命名：phpbox-sidebar-width、phpbox-drawer-height、phpbox-theme
- 首次打开使用"紧凑"预设

### 4.4 响应式断点

| 断点 | 变化 |
| --- | --- |
| ≤ 1280px | 内容 padding 缩到 24px，摘要卡紧凑 |
| ≤ 960px | 侧边栏切图标模式（64px），导航文字隐藏，header 竖排 |
| ≥ 1600px | 内容最大宽 1400px，字号 +0.5px |
| ≥ 2200px | 内容最大宽 1680px，字号 +1px |
| ≤ 720px 高 | 纵向间距压缩，抽屉默认 180px |

禁止：

- 禁止出现横向滚动条（表格除外，表格允许内部滚动）
- 禁止出现元素重叠或溢出容器
- 禁止在窄屏隐藏关键操作按钮

### 4.5 布局预设

| 预设 | 侧边栏 | 抽屉 | 场景 |
| --- | --- | --- | --- |
| 紧凑（默认） | 200px | 160px | 13" 笔记本 |
| 标准 | 232px | 220px | 15–16" |
| 宽屏 | 280px | 320px | 27"+ 外接 |

约束：预设入口只能在设置页（设置 → 布局），不得做成悬浮菜单。

## 六、交互语义（按操作类型分类）

### 6.1 乐观更新（立即反馈，失败回滚）

| 操作 | 反馈 | 回滚 |
| --- | --- | --- |
| 切换站点 PHP 版本 | 下拉立即变 + "切换中…" | 失败恢复旧值 + Toast |
| 修改端口 | 输入框立即更新 | 失败恢复旧值 |
| 展开/收起只读内容 | 立即 | 无需 |

### 6.2 确认式（必须先弹窗）

| 操作 | 弹窗类型 |
| --- | --- |
| 安装服务 | 普通弹窗（版本 + 命令预览） |
| 卸载服务 | 危险弹窗（勾选 + 输入版本号 + --purge 选项） |
| 删除站点 | 危险弹窗（勾选 + 输入域名） |
| 删除备份 | 危险弹窗（勾选 + 输入文件名） |
| 清理离线缓存 | 危险弹窗（勾选 + 输入 svc/ver） |
| 恢复备份 | 危险弹窗（勾选 + 输入文件名） |
| 添加扩展 | 普通弹窗（带重建警告） |

### 6.3 危险弹窗的强制结构

```text
┌─ ⚠ 图标 + 标题 + 描述 ─────────────┐
│                                     │
│ 警告清单（红底）                     │
│   ⚠ xxx 会被删除                    │
│   ✓ xxx 会保留                      │
│                                     │
│ 勾选确认（必填）                     │
│   ☐ 我了解 xxx                      │
│                                     │
│ 输入匹配（必填）                     │
│   请输入 xxx 以确认：[____]          │
│                                     │
│ 将执行                              │
│   $ phpbox xxx                      │
│                                     │
│           [取消]  [确认卸载]         │
└─────────────────────────────────────┘
```

约束：

- 三个条件（勾选 + 输入匹配）全部满足才能启用确认按钮
- 输入匹配必须精确相等（===），不区分大小写视为违规
- 确认按钮默认禁用，禁用时用 --danger-bg 弱化

【原型已验证】终定稿的 openDangerConfirm 已实现本结构（清单 ⚠/✓ 分色 + 勾选 + 输入 + CLI 预览 + 禁用逻辑）。

## 七、组件规范

### 7.1 按钮

| 类 | 用途 | 色彩 |
| --- | --- | --- |
| .btn | 次要操作 | 中性 |
| .btn-primary | 主操作（每屏最多 1 个） | accent |
| .btn-danger | 危险文本按钮 | danger 文字 |
| .btn-sm | 表格行内操作 | — |

禁止：

- 禁止同一区域出现两个 .btn-primary
- 禁止用 primary 样式表示"取消"

### 7.2 徽章

| 类 | 用途 |
| --- | --- |
| .chip | 中性信息（端口、大小） |
| .chip-accent | 高亮信息（版本号、已解析） |
| .status-pill | 状态（运行中/已停止/失败） |

status-pill 变体：pill-ok / pill-off / pill-warn / pill-err。

### 7.3 表格

- thead 必须 text-transform: uppercase + 小字号
- tbody tr:hover 必须有背景变化
- 窄屏必须横向滚动（overflow: auto + min-width）
- 操作列固定宽度，右对齐

### 7.4 弹窗

- 最大宽度：普通 480px，大 620px
- 最大高度：88vh（超出内部滚动）
- 必须有 Esc 关闭
- 遮罩点击关闭；**危险弹窗除外（必须显式点击取消或确认）**
- 右下角必须有拖拽手柄

### 7.5 任务抽屉

- 两态：收起（42px，仅头部） / 展开（--drawer-height）
- 默认收起
- 任务启动时自动展开
- 用户点击箭头切换两态
- 箭头图标随状态旋转（收起 ↑，展开 ↓）
- 展开时显示完整日志

禁止：

- 禁止出现"完全隐藏"的第三态
- 禁止点击关闭按钮时销毁任务状态

【原型已验证】常驻底条 + 42px 收起态实测符合。

### 7.6 Toast

- 位置：右下角，堆叠显示
- 三种类型：ok（绿）、err（红）、info（蓝）
- 默认停留 3.2 秒
- 长文本（如含路径）停留 5 秒
- 内容必须包含：动作 + 对象 + 结果

### 7.7 空状态（四要素）

```text
[图标 42px]
[标题：说明"没有什么"]
[描述：为什么需要]
[按钮：下一步做什么]
```

禁止：空状态不能只有图标，必须有按钮。

## 八、具体功能约束

### 8.1 站点面板

| 列 | 内容 | 交互 |
| --- | --- | --- |
| 域名 | 首字母图标 + 域名 | 点击新标签打开；hover 显示下划线 + 外链图标 |
| PHP 版本 | 下拉选择器 | change 立即切换，乐观更新 |
| 根目录 | 虚线路径按钮 | 点击复制 + 尝试打开文件管理器 |
| 健康 | 徽章 | 只读 |
| Hosts | 已解析徽章 / "加 hosts"按钮 | 未解析时内联按钮 |
| 操作 | 伪静态图标 + 删除图标 | 见下 |

伪静态按钮约束：

- 不是独立列，在操作区
- 未配置：灰色图标；已配置：accent 高亮
- 点击弹出配置弹窗（见 §8.2）

### 8.2 伪静态配置弹窗

- 顶部框架网格：**9 种框架卡片**（含"无"和"自定义"，【修订】原稿 8 种，与原型实测对齐补 symfony）
- 每个卡片：图标 + 名称 + 类型标签
- 中部：可编辑 textarea，选择框架时自动填充该框架规则
- 底部：可折叠的规则预览
- 支持 Tab 键插入 4 空格缩进
- 应用按钮：只有在"框架变了"或"文本被改过"时才可点击
- 未改动时显示"当前配置"且禁用

禁止：

- 禁止只读展示规则
- 禁止选择框架后不可编辑
- 禁止未改动时也能点击应用

内置规则以用户权威参考为准（§9 修订记录附表）：Laravel/CodeIgniter=try_files…$query_string；ThinkPHP/ThinkCMF=if(!-e)+rewrite s=$1；Yii2/WordPress=try_files…$args；Discuz/DedeCMS=专用 rewrite 组；Symfony=custom 起步。

### 8.3 PHP 扩展管理弹窗

区块顺序固定：

1. 预设档案（默认 / minimal / web / debug，默认选中）
2. 已启用扩展（toggle chips）
3. 常用可添加（toggle chips）
4. 添加扩展（输入框 + 按钮）

toggle 行为约束：

- 点击 chip 只切换背景色（on ↔ off）
- 禁止删除 chip
- 禁止移动 chip 到另一个区域
- "已启用"区的 chip 保持位置，"常用"区的 chip 保持位置
- 选中态用 --accent-bg + --accent 边框；未选中用灰底
- 计数：每个区域右侧显示"X / Y 已选"

【原型已验证】终定稿 openPhpExtensionsModal 为 toggle 原位模型 + 四档预设，符合本条。

### 8.4 备份面板

- 每个归档行必须有：下载 / 恢复 / 删除
- 下载按钮必须带下箭头图标
- 下载在浏览器中触发 Blob；在桌面版弹出原生"另存为"

### 8.5 设置面板

布局分组必须在最顶部，包含：

- 预设档案按钮（紧凑 / 标准 / 宽屏 / 重置）
- 侧边栏宽度滑块（64–380px）
- 日志面板高度滑块（120–600px）

路径类字段必须带"浏览"按钮：

- 用 File System Access API（Chrome/Edge/Safari 支持）
- 降级：input[webkitdirectory]
- 桌面版：调 SelectDirectory() 原生对话框

保存时：弹出 Toast 显示具体改了哪些项，标注需重装的项。

【原型已验证】布局预设/滑块/浏览按钮三项实测在位。

## 九、文案规范

### 9.1 中英文混排

- 中文文案 → 中文标点
- 代码/路径/版本号 → 用 `<span class="mono">` 包裹
- 【修订】中英文之间**加半角空格**（盘古之白，如"PHP 版本"），与既有文案实践一致；原草案"不加空格"及示例（两个相同字符串）作废

### 9.2 空状态文案（四要素必填）

| 页面 | 标题 | 描述 | 按钮 |
| --- | --- | --- | --- |
| 站点 | 还没有站点 | 创建第一个站点，就能用浏览器访问本地项目。 | 新建站点 |
| PHP | 还没有安装 PHP | 安装一个 PHP 版本，就能开始创建站点。 | 安装 PHP |
| MySQL | 还没有安装 MySQL | 安装 MySQL，为你的应用准备数据库。 | 安装 MySQL |
| 备份 | — | 备份文件保存在 backups/ 目录 | 立即备份 |

禁止：空状态用"暂无数据"这类无意义文案。

### 9.3 Toast 文案

- 格式：✓/⚠ + 动作对象 + 结果
- 成功：✓ 站点 demo.test 已创建成功
- 失败：⚠ 端口 80 已被占用
- 信息：没有改动

### 9.4 危险弹窗文案

警告清单必须区分：

- 会删除的项：红色 + ⚠ 前缀
- 会保留的项：灰色 + ✓ 前缀
- 确认勾选文案必须以"我了解"开头。

## 十二、状态与数据

### 12.1 前端状态（Pinia）

```typescript
stores/
├── sites      # [{ domain, php, hostAdded, health, rewrite }]
├── services   # { php: [], mysql: [], pgsql: [], redis: [], nginx: [], go: [] }
├── tasks      # { current, history[] }
├── offline    # { tree, totalBytes, lastVerifyAt }
├── settings   # env 派生
└── ui         # { modalStack, drawerExpanded, theme, routeMemory }
```

### 12.2 引擎状态（九态）

```text
absent → preparing → configured → starting → healthy/committed
                                     ↓
                                   failed → rolling_back → rolled_back
```

必须映射为 UI 徽章（详见 §7.2）。

### 12.3 禁止

- 禁止在前端计算业务逻辑（版本号比较除外）
- 禁止在前端拼接文件路径（用引擎返回的完整路径）。【阶段 0 豁免】bash 桥阶段由前端单点派生（CONFIG_PATH 助手），Go 引擎后必须改绑定返回
- 禁止把敏感信息（密码明文）存到 Pinia 全局 store

## 十三、错误处理

### 13.1 错误分类

| 类型 | UI 表现 |
| --- | --- |
| 引擎返回错误 | 任务抽屉标红 + 阶段定位 + 建议 |
| 网络/连接错误 | 顶部横幅 + 重试按钮 |
| 用户输入错误 | 输入框红框 + 提示 |
| 未知错误 | 弹窗显示原始错误 + 复制按钮 |

### 13.2 失败日志的必须内容

```text
[失败] 退出码 1

排查建议：
  1. xxx
     https://...
  2. 或运行：phpbox doctor
```

禁止：失败时只显示"操作失败"四个字，不给任何排查方向。

## 十五、性能约束

- 首屏加载 < 500ms（桌面版）
- 表格 100 行以上必须虚拟滚动
- 任务日志超过 5000 行必须截断
- 禁止在 render() 里做耗时计算
- 禁止在 input 事件里做同步 IO
- 图片（如果有）必须用 SVG 或 WebP

---

## 十六、代码规范

### 16.1 命名

- CSS 类：kebab-case（drawer-toggle）
- JS 函数：camelCase
- 常量：UPPER_SNAKE_CASE
- 事件处理：onXxx（onDown / onMove / onUp）

### 16.2 注释

- 复杂逻辑必须有块注释说明"为什么"
- 每个 openXxxModal 函数顶部注明"由谁触发 / 干什么 / 成功后干什么"
- 危险操作的函数顶部标注 `// ⚠ 危险操作，必须二次确认`

### 16.3 禁止

- 禁止 var（必须 const / let）
- 禁止 innerHTML = xxx（除非已 esc()）
- 禁止内联 onclick="..." 属性
- 禁止魔法数字（必须提取为常量）
- 禁止 setTimeout(..., 0) hack

---

## 十七、无障碍（最低要求）

- 所有图标按钮必须有 title 属性
- 弹窗必须有 aria-modal="true"
- 键盘 Tab 顺序必须合理
- 颜色对比度 ≥ 4.5:1（正文）
- 焦点状态必须有视觉反馈（outline 或 box-shadow）

---

## 十八、变更流程

任何对 UI 的改动，必须：

1. 先改本文档（记录为什么要改）
2. 再改代码
3. 更新命令面板（如果新增/删除命令）
4. 更新测试（如果有）
5. 在 PR 描述里链接本文档的对应章节

禁止：

- 禁止直接改代码不改文档
- 禁止删除已有功能而不记录
- 禁止新增功能而不更新导航/命令面板

---

## 十九、一句话总纲

看目录名就知道它属于哪条线，看颜色就知道它是什么状态，看按钮就知道下一步做什么，看 Toast 就知道刚才发生了什么。

任何 AI 或开发者在改动这个 UI 时，只要记住这一句，就不会偏离。
